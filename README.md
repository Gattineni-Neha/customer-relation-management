# Customer Relation Management Application

A full-stack CRM system built with Python, Flask, and MongoDB featuring 3-level role-based authentication, interactive dashboards, and complete CRUD operations.

## Features
- Create, Read, Update, Delete customers
- 3-Level Role-Based Auth: Admin, Staff, User
- Interactive dashboards with charts
- Responsive UI

## Tech Stack
- Backend: Python, Flask
- Database: MongoDB
- Auth: Flask-Login
- Frontend: HTML, Bootstrap, Chart.js
